# Codex Mic Remote

スマホのブラウザから、Macの **現在フォーカス中のCodexウィンドウ** を操作する小さなローカルアプリです。Codex Voice通話内のマイク、明示的な新規チャット作成・音声会話開始、モデル・推論エフォートの選択を扱えます。macOS全体の入力ミュートは変更しません。

## 使い方

### Macアプリで起動（推奨）

配布物にある `dist/Codex Mic Remote.app` をダブルクリックします。下の「起動」ボタンを一度押すだけで、ターミナルや `npm start` は不要です。起動後の画面には同じWi-Fi向けのURL、10分間有効な6桁コード、QRコードを表示します。

配布済みアプリは Apple Silicon / macOS 15 以降向けです。未公証のローカルアプリなので初回は、Finderでアプリをcontrolクリックして「開く」を選んでください。

### アップデート

ランチャーの **「アップデートを確認」** は [GitHub Releases](https://github.com/Nisss78/codex-mic-remote/releases) の最新安定版を確認します。更新があれば、明示的に確認した後でアプリ本体と `SHA256SUMS.txt` をダウンロードし、SHA-256 が一致する場合だけ入れ替えて再起動します。既存アプリは同じフォルダに日時付きバックアップとして残します。GitHubへ接続できない、アセットが不足している、またはチェックサムが一致しない場合は、現在のアプリを変更しません。

QRコードには短期の接続先とペアリングコードだけが入り、ログイン済みセッションのトークンは入りません。スマホではQRを読み取って開いたページをホーム画面に追加すると、次回以降はアイコンからすぐ開けます。

- 初回は macOS の「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で、実行元（`Codex Mic Remote` / `codex-voice-ax`）を許可します。ランチャーの **「アクセシビリティ設定を開く」** は、起動状態にかかわらずこの設定画面を開きます。権限を変更するのはユーザー自身です。許可の対象名はmacOSの表示に従ってください。
- ランチャーは、8787番ポートを使用中のプロセスを勝手に停止しません。ランチャー自身が起動したサーバーだけは、0600権限で保存した管理トークンとインスタンスIDで照合できるため、表示される **「Codex Mic Remote を再起動」** からループバック限定の認証済み終了APIへ安全な終了を依頼して再起動できます。PIDへ直接シグナルは送りません。確認できないプロセスや旧版は停止せず、元のアプリまたはターミナルから停止するよう案内します。
- 「停止」は、このランチャーが起動したサーバーだけを停止します。アプリを終了した場合も同様です。ウィンドウを閉じるだけならサーバーは継続し、Dockからアプリを開き直せます。登録済みスマホはMacのアプリケーションサポート領域に保存され、30日間はサーバー／Macの再起動後も再入力不要です。各スマホの「このスマホの接続を解除」で取り消せます。IPアドレスが変わった場合、または30日経過後は再ペアリングが必要です。
- Node.js 18以降は引き続き必要です。ビルド済みアプリはビルド時に使ったNodeを優先し、一般的なHomebrew/`/usr/local`の場所も探します。

ソースからMacアプリを作り直す場合だけ、Macで一度 `npm run build:app` を実行してください。結果は `dist/Codex Mic Remote.app` です。

### ターミナルから起動

1. Mac のこのフォルダで `npm start` を実行します。
2. ターミナルに出る `http://…:8787` を同じ Wi-Fi のスマホで開き、同時に出た6桁コードを入力します。
3. Codex Voice 通話中なら、現在の状態を読み取り、ボタンでマイクを切り替えられます。新しいチャットと「音声会話を開始」は、スマホ側の各ボタンを明示的に押した場合だけ動作します。

### モデルと推論エフォート

リモコンの「会話をセットアップ」から、最初に **「モデル・エフォート候補を読み込む」** を押してください。この明示操作時だけ、いま前面にあるCodexウィンドウのメニューを読み取り、実際に表示・有効になっている候補だけをスマホへ表示します。モデルやエフォートを選ぶと、同じ前面ウィンドウの対応メニューだけを操作します。

Codexの画面に該当のピッカーやボタンが見つからない場合は、その操作を無効化して理由を表示します。候補の自動推測や、バックグラウンドの別チャットの操作はしません。

同じスマホでは、ページ更新や画面を閉じて開き直しても再入力は不要です。有効期間はペアリングから30日です。Mac側のサーバーやMacを再起動しても維持されます。

### ホーム画面アプリについて

スマホでQRを読み取った後、Safariの共有メニューから「ホーム画面に追加」を選ぶと、次回からアイコンで直接リモコンを開けます。LAN の `http://` 接続でもこのホーム画面ショートカットは使えます。

Web Manifest は同梱していますが、Service Worker（オフラインキャッシュを使う完全なPWA）はHTTPSが必要です。LANのHTTPでは安全のためService Workerを登録しません。自己署名証明書の信頼設定や外部公開トンネルは、この配布物では行いません。

## 安全性と制約

- 公開されたCodex Voice用のリモート操作 API は使っていません。Codexデスクトップアプリがアクセシビリティ経由で公開する、前面ウィンドウ内のラベル付きコントロールだけを探して押します。
- サーバーは10分だけ有効な6桁ペアリングコード、8回失敗時の5分ロック、HttpOnlyセッション、接続元IP固定を使います。インターネットに公開しないでください。
- アプリ更新や表示言語によりボタンラベルが変わると安全に「利用不可」と表示し、何も操作しません。モデル／エフォート候補も、ユーザーが読み込みを指示した時点で可視かつ有効な項目だけを返します。
- マイクをオフにしても、Voice接続自体を終了するものではありません。

## 開発時の確認

`npm test` はネットワークやCodex Voiceを操作しない使い捨てテストです。実際のトグル検証は音声通話を使っていないときにだけ行ってください。
